# 🎨 Aula Flexbox

Atividade avaliativa individual: revisão de Flexbox e JavaScript, reproduzindo um layout de referência com CSS puro e praticando manipulação de arrays, objetos e consumo de API.

## 📋 Enunciado

Revisar os conceitos de Flexbox e JavaScript, reproduzindo com CSS um layout de referência composto por blocos coloridos organizados em linhas e colunas. Além disso, praticar:

- Manipulação de arrays e objetos em JavaScript (busca de valores mínimo/máximo, soma condicional, agrupamento de dados)
- Consumo de API pública (ViaCEP) utilizando `fetch`, com tratamento de erros

## 🛠️ Tecnologias utilizadas

- HTML5
- CSS3 (Flexbox)
- JavaScript (Fetch API)

## ▶️ Como executar

Basta abrir o arquivo `index.html` no navegador (recomenda-se usar a extensão **Live Server** do VS Code) e acompanhar os resultados dos exercícios de JavaScript pelo console do navegador.
